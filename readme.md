# SQL Server Basics

This repository contains notes, examples, and exercises from a basic
course on **Microsoft SQL Server**, **Transact-SQL (T-SQL)**, and
**SQL Server Management Studio (SSMS)**.

## Technologies

- **Database Management System:** Microsoft SQL Server
- **Language:** Transact-SQL (T-SQL)
- **Development Environment:** SQL Server Management Studio (SSMS)

## Topics

The course covers basic SQL concepts, including:

- Creating and managing databases
- Creating tables
- Data types
- `SELECT` statements
- `WHERE` and filtering
- `ORDER BY`
- Aggregate functions
- `GROUP BY` and `HAVING`
- `INSERT`, `UPDATE`, and `DELETE`
- Primary and foreign keys
- `JOIN` operations
- Subqueries
- Common Table Expressions (CTEs)
- Basic database relationships
